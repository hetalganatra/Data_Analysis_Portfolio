# SQL Ride Sharing Data Analysis

## Purpose
- SQL data cleaning techniques
- Data validation skills
- Data analysis and insights generation

## Project Overview

This project analyzes a ride-sharing dataset using SQL. It focuses on data cleaning, validation, and business insights.

## Data Cleaning

- Handled missing email and phone values
- Removed invalid phone numbers
- Fixed incorrect ratings and payment values
- Checked and corrected trip timestamp issues
- Ensured proper relationships between tables

## Analysis Performed
- Total number of trips
- Revenue calculation
- Average fare, distance, and duration
- Peak trip hours
- Surge pricing impact
- Trip status distribution

## Key Insights
- Peak demand occurs during evening hours
- Surge pricing increases fare significantly
- Most trips occur without surge pricing
- Data quality issues were found in user and trip data

## Tools Used
- MySQL
- SQL (Joins, Aggregations, CASE, Subqueries)
- VS Code

## Overview
This project integrates five retail datasets — sales, customers, products, stores, and calendar — to perform end-to-end data analysis and predictive modeling.

## Key Tasks
- Data integration using Python
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales trend and customer behavior analysis
- Predictive modeling for future sales

## Dataset
- sales.csv
- customers.csv
- products.csv
- stores.csv
- calendar.csv

## Outcome
- Identified sales trends and customer patterns
- Built predictive insights for business decision-making

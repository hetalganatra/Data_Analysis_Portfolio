# Employee Attrition Dashboard (Excel)
An interactive Excel dashboard analyzing employee attrition patterns to identify key drivers of turnover and retention challenges.

## Project Overview
This project analyzes employee attrition data using Excel, Pivot Tables, and visualization techniques to uncover trends across departments, performance levels, hiring sources, and managers.

It also focuses on identifying key business problems driving attrition and provides data-driven solutions to improve employee retention and workforce stability.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization (Charts & KPI Cards)

## Key Insights

- High attrition in Production (40%) and IT (36%) indicates risk to core operations, as frequent turnover can disrupt productivity and increase hiring costs.
- 85% voluntary attrition suggests employees are leaving by choice, pointing to underlying dissatisfaction and better external opportunities.
- Attrition drivers—better opportunities (24%), dissatisfaction (17%), and pay (13%)—highlight gaps in compensation and work environment.
- Higher attrition among low performers (Needs Improvement 56%, PIP 38%) indicates gaps in performance management and employee support.
- Higher attrition from sources like Google (100%) and Indeed (61%) compared to referrals (24%) suggests differences in hiring quality and cultural fit.
- Variation in attrition across managers (up to 62%) indicates leadership and team environment significantly impact employee retention.

# Employee Salary Analytics Dashboard (Excel)
An interactive Excel dashboard analyzing employee compensation across departments, roles, and performance using Pivot Tables and data visualization.

## Project Overview
This project analyzes employee salary data using Excel, Pivot Tables, and dashboard visualization techniques to uncover key insights about compensation across departments, roles, and performance levels.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization (Charts & KPI Cards)

## Key Insights
- Executive and technical roles dominate the highest salary range.
- Operational roles earn significantly lower salaries.
- Salary is primarily driven by role hierarchy and department.
- Performance and gender have a relatively smaller impact on overall compensation.
